# Legacy scripts

Kept for reference only; not maintained and not needed with Docker Compose.

- `3_install_ros2_foxy.bash`: old bare-metal setup (ROS2 Foxy, Node.js, `.bashrc` exports). The project now targets ROS2 Humble in Docker.
- `build.bash`: old bare-metal `colcon build` of `aims_ws`. Run it from the repository root.

Paths inside these scripts assume their original location at the repository root (`build.bash`) and in `scripts/` (`3_install_ros2_foxy.bash`).
